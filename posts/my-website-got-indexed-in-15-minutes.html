My Website Got Indexed in 15 Minutes

By Ubaid Ali — August 12, 2025
Tags: Blogging, GitHub, SEO

My Website Was Indexed Quickly

I was amazed when my GitHub Pages website got indexed by Google in just 15 minutes. Even more surprising, I built the entire site in four hours without being a coding expert.

For three years, I struggled with indexing issues on my Blogger site. I tried changing themes 45 times, editing robots.txt, and setting up redirects, but Google kept flagging a redirect error due to Blogger’s m=1 mobile URL issue, which many beginners don’t know about. With GitHub Pages, I faced no errors and got instant indexing.

Blogger’s m=1 Problem (A Built-In Issue)

If you use Blogger, you might have faced the m=1 redirect issue. It’s not a theme or settings problem—it’s a core issue with Blogger that has no simple fix.

Google uses two bots to crawl websites: one for desktop and one for mobile. On Blogger, the mobile bot sees two URLs: example.blogspot.com (desktop) and example.blogspot.com/?m=1 (mobile). Although both show the same content, Google treats them as duplicate pages and flags a redirect error, which confuses its algorithm.

I tried custom domains, robots.txt edits, and canonical tags, but nothing worked. Blogger’s SEO is not effective in 2025.

WordPress: Free vs. Paid

WordPress.com (Free Version) — Not Ideal

The free version of WordPress.com is limited. It doesn’t allow AdSense approval, offers few themes and plugins, and requires payment for a custom domain.

WordPress.org (Self-Hosted) — Better but Costly

The self-hosted version is better. You can use AdSense with original content and access unlimited themes and plugins with a paid domain. However, you need to pay for hosting and a domain to start, and without traffic, even a great site won’t earn money.

The key issue is that you need visitors to make money. Without traffic, even the best WordPress site won’t generate income.

Why GitHub Pages Worked for Me

After years of frustration with Blogger and researching WordPress, I tried GitHub Pages, and it was a game-changer.

GitHub Pages offers fast indexing (15 minutes for me), free hosting, full control over code (with help from tools like ChatGPT), and no m=1 redirect issues.

However, it requires basic coding skills (HTML, CSS, Markdown), has no built-in CMS, and lacks plugins, so you add features manually. With tutorials and ChatGPT, building a professional site is manageable.

Can You Monetize GitHub Pages with AdSense?

I’m still testing whether Google AdSense will approve a GitHub Pages site. In the Google AdSense Community, I learned that AdSense focuses on content quality and originality, not whether you have a custom domain.

Earnings come from real visitor impressions, not bots. I read conflicting information—one blog claimed AdSense approval on a GitHub domain, while a Quora post said it’s not possible. So, I’m experimenting myself.

My site is indexed (step one done). Next, I’ll build more pages (step two) and apply for AdSense (step three). I can’t guarantee approval, but I’m sharing my journey to test if GitHub Pages can be monetized.
